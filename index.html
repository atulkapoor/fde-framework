fde-framework

An open-source framework for Forward Deployed Engineers — from a client problem statement to a runnable, deployable AI project, with every decision traced to a fact.

GitHub PyPI Releases Worked example 

pip install fde-framework
fde start acme --statement "Extract fields from supplier invoices."

What a Forward Deployed Engineer gets

  • Discovery that compounds — prose, PDFs, sample pairs, role-scoped interviews and hardware scans feed one profile; provenance decides conflicts, and disagreement between people is surfaced as a finding.
  • Seven gates before building — verified data access can never be waived; every waiver ships in the project's RISKS.md with its reason.
  • Decisions with receipts — simplest applicable approach per component, cited evidence, named rejected alternatives, deterministic to the fingerprint: same facts, byte-identical project.
  • A real project out — pipeline with approval gates and critics, three-layer evals (golden / edge / adversarial), runbooks, SLOs, compliance docs; on-prem, hybrid, customer-VPC and air-gapped topologies.
  • LLMs as proposers, never deciders — reading briefs, mining vocabulary, implementing against a fenced eval harness, judging freeform output after human calibration.

Who it is for

Forward Deployed Engineers, AI consultants and solutions engineers delivering LLM systems into enterprise environments — especially where data residency, air-gapped deployment, unit economics and evaluation ownership decide whether the engagement survives contact with production.
