# Code of conduct

This project is built from the craft of real engagements, and the standard
for how people treat each other here is the same as on a good engagement
team.

**Expected:** technical disagreement argued from evidence; reviews that name
the problem, not the person; patience with newcomers; credit where it is
due.

**Not tolerated:** harassment, personal attacks, discrimination, sustained
disruption, or publishing others' private information. One warning; then
removal from the project's spaces.

Two rules specific to this project:

- **Disagreement is a finding, not a conflict.** The framework treats two
  people differing as valuable information, and so does this community.
  Argue the claim, cite the evidence, and it stays productive.
- **Client material never enters this repository** — in code, issues,
  discussions or commit messages. Naming a client or a private individual
  in any project space is treated as seriously as committing their data.

Report conduct issues to the maintainer via the contact on the GitHub
profile, or through a private security advisory if the report itself is
sensitive. Reports are handled confidentially.
